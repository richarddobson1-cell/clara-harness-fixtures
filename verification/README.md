# Independent verification

This directory holds independent re-scorings of a released battery by
assessors with no part in authoring the fixtures, the screens, or the
recorded verdicts. Each assessor worked solely from the public contents
of this repository — the battery prompts, the screen definitions, and
the recorded replies — and scored every reply before consulting the
recorded verdicts in the transcripts' `scores` section.

The purpose is narrow and stated as such in the paper (§4.11): the L1
screens are deterministic, so a recorded verdict should reproduce when
an outsider applies the released screens to the released replies. These
files are that reproduction, published so the verification is itself
checkable rather than merely asserted.

Assessors are named where they have consented; where an assessor prefers,
they are identified by role, with identity held on file and available to
the journal's editorial office on request. Where an assessor has a
relationship with the research programme, it is disclosed in their file.
